# Поверхность вращения — закраска Гуро и Фонга

Java-приложение на Swing строит поверхность по редактируемому профилю и показывает три режима закраски: плоский, Гуро и Фонга. Объект можно вращать мышью, перемещать вдоль оси Z и рассматривать движущейся камерой.

## Запуск

Нужен установленный JDK с командами `javac` и `java`. В терминале перейдите в папку с исходными файлами и выполните:

```bash
javac -encoding UTF-8 *.java
java RevolutionStudio
```

В окне программы: **Профиль** изменяет образующую, **Закраска** переключает метод, **Сегментов** задаёт детализацию. Перетаскивание левой кнопкой мыши поворачивает объект вокруг Y, колесо меняет масштаб. Кнопки движения запускают анимацию объекта вдоль Z или камеры; одновременно эти две анимации не работают.

## Основные формулы

**Построение поверхности.** Для точки профиля с радиусом `r` и высотой `h`, повёрнутой на угол `φ` вокруг Y:

```text
x = r cos φ,     y = h,     z = r sin φ.
```

Нормаль треугольника — нормированное векторное произведение двух его рёбер. Нормаль вершины — нормированная сумма нормалей прилегающих треугольников.

**Освещение.** `N` — единичная нормаль, `L` — направление на источник, `V` — направление на камеру, `d` — расстояние до источника:

```text
R = 2(N · L)N − L
A(d) = 1 / (1 + 0,035d²)
I = 0,16 + A(d) [0,70 max(0, N · L) + 0,48 max(0, R · V)²⁸]
```

Значение `I` ограничивается диапазоном `[0, 1]` и преобразуется в оттенок серого.

**Закраска.** Для пикселя треугольника барицентрические веса `α`, `β`, `γ` показывают вклад его вершин; `α + β + γ = 1`.

| Метод | Как находится яркость пикселя |
| --- | --- |
| Плоская | Один расчёт освещения в центре грани с её нормалью; яркость постоянна по всей грани. |
| Гуро | Освещение рассчитывается в вершинах, затем `I = αI_A + βI_B + γI_C`. |
| Фонга | Нормаль интерполируется: `N = normalize(αN_A + βN_B + γN_C)`. Затем освещение рассчитывается для пикселя. |

Глубина пикселя также интерполируется по весам. Z-буфер оставляет поверхность с наименьшей глубиной относительно камеры. Для движения объекта вдоль Z используется `z(t) = 2,20 sin(2πt)`.
